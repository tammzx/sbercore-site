# Brand logos

Place optional square logo files in this directory:

- `yadro.svg` or `yadro.png` — ЯдроСбер
- `gigachat.svg` or `gigachat.png` — GigaChat
- `sber.svg` or `sber.png` — Сбер

SVG is preferred. If SVG is missing or cannot be loaded, the site tries PNG;
if both are missing, it renders the built-in fallback mark.
